CyberGuard SIEM Manager

Reference build v1.0.0 — a compact host-based intrusion-detection manager for SME security operations.

This is the compliance-evaluation reference build. The full CyberGuard product ships with agents, an AI SOC-analyst assistant, and Wazuh integration — see the vendor documentation.

60 months from release (CRA Article 13(8)).

What the product does

  • Ingests logs from endpoint agents (Linux syslog/journald, Windows Event Log, macOS unified log).
  • Correlates events into alerts and forwards to an OpenSearch/Elasticsearch backend.
  • Provides a web UI for the SOC analyst to review alerts.
  • Runs active-response scripts on registered agents (block IP, kill process, quarantine file).
  • Optional local AI-assisted incident triage (opt-in, no cloud calls).
